# Komika v0.3.0

**Changes since [v0.2.1](https://github.com/snowmerak/komika/releases/tag/v0.2.1)**

This release makes archive reading and page navigation substantially more responsive, moves expensive image scaling away from the UI thread, and adds Komika's first standalone marketing site. It also adopts the Mozilla Public License 2.0.

## Highlights

### Faster archive reading

* **CBZ/ZIP random access** — ZIP pages use one indexed archive reader and direct member offsets instead of repeatedly walking the archive.
* **Demand-driven RAR/7z cache** — A page is extracted only when first requested, then reused from a per-open disk read cache capped at **1 GiB**. This is especially helpful for solid archives where repeated traversal is expensive.
* **Bounded temporary storage** — Seekable archive streams retain the existing **2 GiB** per-entry and active-comic aggregate limits. Read and stream caches are removed when the work is closed.
* **Clear source lifetime** — If an opened archive is moved or deleted, already cached pages remain usable while uncached content reports an error instead of silently serving stale data.

### Responsive ±10 page preloading

* The reader now keeps a **±10 page** window around the active page, including complete spreads in double-page modes.
* Visible page requests always take priority. Background preload work uses only an idle load slot, so quickly changing pages is not forced to wait behind the full preload window.
* Video, audio, and non-PDF streamed media remain visible-only to avoid holding unnecessary streams and decoders.

### Smooth first, high quality second

* Images render immediately with the browser's **Smooth** path; expensive scaling never blocks the first visible frame.
* High-quality work is limited to pages within **±2** of the active page and to the settled visible viewport tile.
* **High quality** tiles run through a bounded Go path with up to two parallel workers, Catmull-Rom scaling, and a five-page / **384 MiB** decoded-image LRU.
* HQ results are returned through Komika's loopback media server. Temporary PNGs and capability tokens are released after consumption.
* **NoHalo** and **xBRZ**, plus fallback when host scaling fails, run in a dedicated **Web Worker** rather than on the UI thread.
* Stale results from an earlier zoom, pan, or page state are discarded instead of overwriting the current frame.
* Animated GIFs continue to bypass canvas filters so animation is preserved.

### Desktop and project updates

* The main window now starts **maximized** without the fixed-size/fullscreen conflict from earlier iterations.
* Added a Vite-based static marketing site under `site/`, built with the Merak Protocol Design System and existing Komika brand assets.
* Added `package:docker:all` for multi-platform Docker packaging orchestration. Architecture-specific `wails-cross:$ARCH` images now make Linux ARM64 CGO builds reliable from amd64 hosts, and raw executables are retained with target-qualified names.
* Updated Merak Protocol Design System dependencies used by the app and site.
* Added the **Mozilla Public License 2.0** and corrected license documentation in all README translations.

## Upgrade notes

* No library database or reader-preference migration is required.
* RAR/7z readers may temporarily use up to **1 GiB** of disk space per open work; the cache is deleted when that work closes.
* High-quality host scaling requires a still image decodable by the Go backend. Unsupported or failed host work falls back to the Web Worker, and the already-visible Smooth frame remains available if both paths fail.
* Redistributors should review their obligations under the new [MPL-2.0 license](../../LICENSE).

## Known limitations

* Encrypted and multi-volume archives are not supported.
* Dropping multiple files at once is rejected.
* Unreadable PDFs inside multi-entry sources are skipped.
* GIF animation is preserved, but GIFs do not use high-quality canvas filters.
* Platform packaging and code signing may vary between release artifacts.

## Platforms

* Windows (amd64, arm64)
* Linux (amd64, arm64)
* macOS Apple Silicon (arm64)

Available builds are listed under the GitHub Release assets.
